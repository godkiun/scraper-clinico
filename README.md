# Scraper Clínico - Extracción y Procesamiento de Datos Médicos 🩺📊

Herramienta automatizada en Python para la extracción, estructuración y análisis de datos clínicos y literatura médica.

---

## 🛠️ Características Principales
* **Extracción Automatizada:** Web scraping avanzado de registros y publicaciones científicas.
* **Estructuración de Datos:** Conversión de texto no estructurado a formatos JSON y CSV.
* **Interfaz de Usuario Web:** Aplicación web interactiva integrada (`app.py`).

---

## 💻 Uso Rápido

```bash
git clone https://github.com/godkiun/scraper-clinico.git
cd scraper-clinico
pip install -r requirements.txt
python app.py
```
